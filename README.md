## 🚀 Getting Started

To explore or run code samples:

1. **Clone this repo**:
    ```
    git clone https://github.com/mohd-ahtasham-ansari/python-cs50.git
    ```
2. **Navigate to a folder** (e.g., `cd python-cs50/Loops`)
3. **Run a Python script**:
    ```
    python filename.py
    ```

All code is written to be compatible with Python 3.x.
